# Brand marks

Monochrome SVG marks from [Simple Icons](https://simpleicons.org) (the icon set
is CC0; each mark remains the trademark of its owner). Used editorially in the
MCP setup diagrams to identify the software each guide covers. Unmodified
outlines, single colour, no implication of endorsement or affiliation.

| File | Mark | Owner |
|---|---|---|
| `claude.svg` | Claude | Anthropic |
| `rhinoceros.svg` | Rhino | Robert McNeel & Associates |
| `blender.svg` | Blender | Blender Foundation |
| `qgis.svg` | QGIS | QGIS project / OSGeo |
| `autodesk.svg` | Autodesk (stands in for Revit) | Autodesk |
| `sketchup.svg` | SketchUp | Trimble |
| `unrealengine.svg` | Unreal Engine | Epic Games |

Replace any of these with an official brand-kit file if a vendor asks for it.

Added for the software orbit on services.html:

| File | Mark | Owner |
|---|---|---|
| `autodeskrevit.svg` | Revit | Autodesk |
| `autocad.svg` | AutoCAD | Autodesk |

`autodesk.svg` also stands in for 3ds Max in the orbit — Simple Icons has no
3ds Max mark. Grasshopper and Excel have no CC0 mark either, so those two tiles
use generic glyphs (a node graph and a grid) drawn in `tools/`-style inline SVG,
not imitations of either vendor's logo.
