Quick reference

How to run it.

Turns project material — plans, massing, elevations, materials schedule, site notes, comms brief — into a hero shot brief with copy-paste render prompts (camera, lens, light, mood, entourage). Every visual claim traces to a source or is flagged; the setting stays honest. It is the money-shot workflow, not a general prompt polisher.

Run it

Attach the project material (pack, brief, plan image, schedules) and ask:

Build the hero shot for the DAS cover from this pack.
Money shot for the consultation boards — here's the massing and materials.
Six hero perspectives from this plan, for the competition board.
Batch: use defaults, log them, give me the brief.

It reads everything, builds a fact base, asks a short numbered interview (each with a default — reply "use defaults"), then works one shot per turn: options A/B/C → your choice → that shot's prompts. "Use defaults" answers preferences, not evidence gaps — an unstated feature stays out of the prompt whatever you reply.

The deliverable

SectionWhat it holds
HeaderSources with revision/date, audience, and the illustrative-not-verified statement.
Interview recordEvery question, the answer or the default applied, what's still open.
Source fact baseEach fact tagged Stated / Inferred / [not stated], with the source.
Flags & queriesContradictions, context-honesty flags, declined requests, [to verify] items. Logged, never resolved.
Geometry lockThe fixed facts every prompt obeys; conflicts carried as labelled conservative readings.
Shot listNumber, title, purpose, audience, status.
Per shotPurpose · options A/B/C + recommendation · camera spec · light spec with the orientation reasoning shown · mood · entourage spec · baseline + atmosphere variant prompts · provenance footnotes.
Consistency checklistMaterials, storeys, planting, neighbours, sun logic held constant across the set.

Two variants per shot, always: baseline and one atmosphere variant. Different light, weather or hour — never different facts. Both obey the same lock.

Context honesty rules — applied to every prompt

RuleIn practice
No borrowed geographyNo water, hills, parks or landmarks the site doesn't have. 240 m away isn't "canalside".
Neighbours stay, at true scaleFraming past one is a recorded decision; deleting or shrinking one is not.
Planting at honest establishmentPlanted spec, not year 10. A year-10 image is a separately labelled variant only.
People at plausible densityRender the occupancy the scheme can generate. 46 homes don't bustle.
Sun where the sun goesLight must match real orientation — a north elevation gets no golden hour. [to verify against a sun study].
Unconsented stays outPhase 2, aspirational public realm, third-party land — excluded unless explicitly asked and labelled indicative.
Features must exist in the sourceNo invented fenestration, roof terraces or storeys. [not stated] goes out of frame or stays generic and footnoted.

What it will not do — by design

  • Invent building features. If the pack doesn't say it, the prompt doesn't contain it — this is the whole point.
  • Resolve source contradictions. Two storey counts, two bricks: both logged, the conservative reading labelled, the choice yours.
  • Quietly comply with a misleading request. Decline-or-flag, in writing, in the brief — with the honest version offered alongside.
  • Produce a verified view or AVR. Illustrative CGI only; it names the methodology (LI TGN 06/19 [to verify]) and tells you when you need a specialist.
  • Redesign. Camera, light and atmosphere are the only variables.
  • Dump all six prompts at once in an interactive run — the A/B/C choice per shot is where your judgement enters. Batch mode is the documented exception.
  • Web-search your client or site, or put client names in filenames.

Work the output

  1. Read Flags & queries first — that's the deliverable most likely to save you. Answer the numbered items; each unlocks a prompt.
  2. Check the fact base for Inferred rows: those are the assumptions your image rests on. Orientation is usually the dangerous one.
  3. Generate the baseline before the atmosphere variant, and confirm the geometry before you fall in love with the light.
  4. Re-prompt, don't crop, for a different aspect ratio — the lens choice was made for that frame.
  5. Run the consistency checklist across the finished set before it goes on a board. One image showing established trees undoes the other five.
  6. Caption every image "Illustrative visualisation — not a verified view", and carry any indicative / not consented label onto the file itself.

Remember: the brief equips your decision; it doesn't make it. Thin material correctly produces a short fact base and a long flags table — that is the skill working, not failing. Test drive: run it on the Tanyard Green sample pack and score against its defect key.

Triggering

When Claude reaches for it.

This is the description Claude itself reads to decide whether the skill applies. It is worth knowing, because it tells you exactly how to phrase the ask — and what the skill will decline.

hero-perspective-prompt-builder

Turn project material — plans, massing descriptions, elevation notes, materials schedules, site orientation, audience notes — into a traceable hero shot brief plus copy-paste render-prompt variants (camera, lens, light, mood, entourage) for Nano Banana / Gemini or another image generator. Every visual claim is traced to the source or flagged; entourage and context are kept honest for the stated audience. Use this WHENEVER an architect wants the money shot: "hero shot", "hero perspective", "key view", "cover image for the planning submission / DAS / competition board", "marketing CGI of the scheme", "six hero perspectives from this plan", "build render prompts from this project pack". Do NOT use for polishing a single rough prompt or general archviz prompt engineering (nano-banana-prompt-builder), for camera-locked facade or cladding comparison sets (facade-maker), or to produce verified views / AVRs — it can only flag when one is needed.
