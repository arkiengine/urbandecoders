Quick reference

How to run it.

Forensic health-check of a DXF before anyone scales off it, takes quantities from it, or links it under a model. Measures first, judges second, changes nothing. The file is evidence: it is never modified, purged or re-saved.

Run it

Attach the .dxf and ask:

Audit this DXF. It's a survey we've been sent — can we trust it?
Audit this DXF as a background for our Revit model, and give me the door count.
Why doesn't this drawing scale at 1:50? What units is it in?
Extract the door/window/parking schedule from this DXF and flag anything unsafe.

Best results: say what the drawing is for, who issued it, and whether xrefs came with it. No answers? It still runs, with a purpose-agnostic verdict.

What was not checkedAlways present. The verdict is only as good as this list.

Evidence tags — read nothing without checking its tag:

TagMeaning
[measured]Read directly from the file.
[inferred]Deduced; the basis is stated in the same sentence.
[verify manually]Not knowable from this file; names what to check.

The three scale witnesses — annotated scale, viewport ratio, model text height. All agree: the sheet is measurable. Any disagreement: the sheet was rescaled and nothing printed can be scaled off, whatever the title block says.

What it will not do — by design

  • Touch the file. No purge, fix, translate or re-save — cleanup is prescribed, you perform it on a copy.
  • Declare compliance. Door widths are as-drawn measurements; Part M et al. are separate checks, with documents named [to verify], never figures from memory.
  • Let inference pose as measurement. "Probably mm from the 926 door leaf" stays labelled as a deduction forever.
  • Convert units silently. Two surviving unit hypotheses are both reported, with what would settle them.
  • Present block counts as reality. Counts are as-drawn; coincident duplicates are reported beside every number they would inflate.
  • Pick between contradictions. Rev C vs "REV D", current vs hidden old outline — logged for the issuer, not ruled on.
  • Web-search the practice, client or site unless you ask; no client names in filenames.
  • Decide for you. It reports whether the file is sound; whether it is acceptable for your deliverable is your call.

Work the output

  1. Read the verdict; if a High says stop, stop before opening the file in CAD.
  2. Resolve the revision question with the issuer before any downstream work.
  3. Use the deduplicated counts, never raw insert counts, for schedules.
  4. Run the cleanup list on a copy; keep the received file as the evidence copy.
  5. Send the contradiction items (revision, false dimensions, hidden layers) back to the issuer as questions — they are their defects to rule on.
  6. File the "what was not checked" list with the audit; it defines the checks still owed before the drawing carries real weight.

Remember: the audit tests the file's internal honesty, not the building. A clean audit means the drawing agrees with itself — site verification is still site verification. Test drive: run it on the Selden Row sample (example-input.dxf) and score against selden-row-defect-key.md.

Triggering

When Claude reaches for it.

This is the description Claude itself reads to decide whether the skill applies. It is worth knowing, because it tells you exactly how to phrase the ask — and what the skill will decline.

dxf-audit

Forensic audit of a DXF CAD file before anyone trusts it: measures units, scale, origin and coordinate frame, layer discipline, block and attribute integrity, duplicates and geometry hygiene, then reports verdict-first what the drawing can and cannot be used for — every claim tagged [measured], [inferred] or [verify manually]. Use this WHENEVER an architect or technologist supplies a .dxf (survey, architect's background, consultant's drawing, legacy file) and wants it "audited", "checked", "sanity-checked", or asks "can I trust this file", "what units is this in", "why doesn't this drawing scale", "why is everything miles from the origin", "is this the issued revision", "extract the doors/parking from this DXF", "count the blocks", or "is this safe to link into Revit / import into Rhino or QGIS". Also trigger before any take-off derived from a DXF. Do NOT use for checking a design against regulations, to modify, purge or re-save CAD files, or for native .dwg, .rvt or .3dm — ask for a DXF export first.
