Quick reference

How to run it.

Turns building references (photos, CGIs, or a written project pack) into a shot-by-shot storyboard for a short film — default 30s as three 10-second clips with shared boundary frames, keyframe image prompts, per-clip camera directions for image-to-video tools, and stitch notes. It directs cameras at the scheme as evidenced — it never invents architecture.

Run it

Attach references (min. one exterior + one interior, or a project pack) and ask:

Storyboard a 30-second film of this house — slow dusk reveal.
Here's the film pack for [project] — build the shot list and keyframe prompts.
Turn these renders into a reel for the website. Keyframes for Kling.

It asks 4–8 numbered questions first (each with a default — reply "use defaults"), then delivers. "Use defaults" answers preferences, not evidence gaps — a frame with no reference stays a placeholder whatever you reply.

The deliverable

SectionWhat it holds
ConceptThe arc in 1–2 lines.
Shot-list overviewClip / time / location / camera move / transition out.
Global continuity blockOne block appended to every keyframe prompt — same building, same day.
Clips A–C3 keyframe prompts each (Start/Mid/End) + one motion direction + transition. Shared boundary frames marked "render once, reuse".
Frame checklistF1–F7 (+F8 hold) — exactly what to render, what to reuse.
Stitching & exportStraight cuts on shared frames; overlays done in the edit; timings summed.
Source mapEvery frame tagged: Reference-matched / Relit / Composed / Placeholder.
Queries & placeholders logEvery gap raised, its status, the frames it touches.

The frame math: 3 clips × 3 keyframes, but consecutive clips share their boundary frame — the End of A is the Start of B, the identical still, rendered once. That reuse is what makes the joins invisible: 7 unique frames, not 9.

What it will not do — by design

  • Invent design features. A feature mentioned but not shown in any reference becomes [PLACEHOLDER — see Qn], never a described guess.
  • Redesign the building. Camera, framing and (approved) light are its only variables.
  • Resolve conflicting references silently. Old CGI vs current photo? It asks which governs and records your designation.
  • Relight without telling you. Dusk brief + midday references = a declared departure, tagged Relit in the source map.
  • Assert planning or compliance status. Your captions go in verbatim, marked [to verify], applied in the edit — never baked into frames.
  • Claim tool features from memory. Clip caps and keyframe support are [to verify] against the named tool's docs; otherwise tool-agnostic.
  • Put text or logos in generated frames — typography belongs in the edit.
  • Depict real people or pets, or web-search your client/site; no client names in filenames. It will remind you once that sending references to third-party generators is a disclosure to those services.

Work the output

  1. Read the queries log first — answer the open ones; each unlocks a placeholder frame as a drop-in fix (timings and moves don't change). If the scheme is in Rhino/Revit/SketchUp or a real-time renderer, the fastest fix for a placeholder is a viewport render at the camera position the storyboard specifies — minutes of work, and it counts as evidence.
  2. Generate keyframes in checklist order; refine prompts through your image prompt skill/tool. Render shared frames once; reuse the identical file.
  3. Feed each clip's Start/End frames and its motion direction to the video tool; one camera idea per clip — resist adding more.
  4. Assemble with straight cuts on the shared frames. If a join flickers, fix the frame reuse — don't dissolve over it.
  5. Add overlays, captions (verify them first) and licensed audio in the edit.
  6. Check the source map before the film goes to a client or committee — know which frames are photographs, which are relit, which are composed.

Remember: the storyboard is a draft for you to direct, not a locked edit. A thin reference set correctly produces a short film and a long query list — that is the skill working. Test drive: run it on the Lantern Barn sample pack and score against its defect key.

Triggering

When Claude reaches for it.

This is the description Claude itself reads to decide whether the skill applies. It is worth knowing, because it tells you exactly how to phrase the ask — and what the skill will decline.

building-video-storyboard

Turn building reference material — photos, CGIs, or a written project pack — into a shot-by-shot storyboard for a short architectural film (default 30 seconds as three 10-second clips): shot list with timings, keyframe image-generation prompts, per-clip motion and camera directions written for image-to-video models, and stitching/export notes. Use this WHENEVER an architect, urban designer or visualiser asks for a "video storyboard", "30-second film of this scheme", "flythrough", "reel of the project", "shot list", "keyframes for Runway/Kling/Luma/Veo", "image-to-video prompts", "turn these renders into a film", or supplies references plus a rough film idea ("a slow dusk reveal of this barn"). Also trigger for films for a client presentation, website, planning exhibition or social media. Do NOT use to generate the images or video itself, and do NOT use it to design, redesign or "improve" the building — this skill directs cameras at the scheme as evidenced; it never invents architecture.
