Quick reference

How to run it.

Plans become a takeoff worksheet: every space with its use and area, every route traced, every width measured as drawn, every code figure left as a named [to verify] clause. A measuring and query sheet for the fire engineer — never a capacity, a limit or a compliance verdict.

Run it

Attach the plans, plus the room or area schedule if you have one:

Do an occupancy and egress takeoff on these plans before the fire engineer starts.
How many spaces have we not assigned a use to? And where are the pinch points?
Trace the escape routes on this floor and tell me what's assumed.
Build the capacity sheet so our fire engineer just fills in the factors.

Name the governing code and edition if you know it, and say whether the building is existing or new. Both change which clauses get referenced and the skill will not assume either.

The worksheet

TabWhat it holds
BasisDrawings supplied, revisions, scale, units, governing document (or [not stated]).
Space scheduleRef · Level · Name as drawn · Use (drawn / inferred) · Area · Area basis · Occupancy basis to apply [to verify] · Clause.
Route scheduleEach route traced: origin, path, doors passed, compartment lines crossed, final exit, drawn or assumed.
Measurement listWhat to measure and how: travel distances direct and total, dead ends, door clear widths, corridor pinch points, stair widths, landings.
Capacity checkDrawn widths on the left, empty columns for the engineer's code figures on the right, arithmetic pre-written between.
Query sheetEvery ambiguity, conflict and unknown.
Not checkedWhat this takeoff does not cover.

Tags:

TagMeaning
[as drawn]Dimensioned on a drawing, with sheet and grid reference.
[scaled]Measured off a verified-scale drawing. Lower confidence, flagged.
[as scheduled]From a supplied room or area schedule, not the drawing.
[inferred use]The use driving the occupancy basis is deduced; the deduction is stated.
[assumed route]A route the drawings imply but do not show as an escape route.
[to verify]Needs a code figure, an engineer's decision, or building control agreement.

A corridor labelled 1200 that narrows to 980 at a riser door is a 980 corridor. Widths are recorded at the pinch point, never at the label.

What it will not do — by design

  • Supply any code number from memory — occupancy factors, travel distance limits, width per person, dead-end limits. The document and clause get named and marked [to verify]. This holds even when the figure is well known.
  • Calculate an occupant load from a factor it supplied. Give it the factor and its source, and the arithmetic runs, tagged with that source.
  • Declare compliance, adequacy or a pass.
  • Produce a fire strategy. Compartmentation, suppression, smoke control and alarms are the fire engineer's.
  • Report a door leaf width as a clear width. Clear width is derived and depends on ironmongery and opening angle.
  • Scale off an unverified drawing without tagging every resulting figure.
  • Invent a route to make a space work.
  • Reassure. "That looks like plenty of width" must not appear.

Work the output

  1. Fix the scale question first. A travel distance scaled off a rescaled sheet is a fabricated number, and everything downstream inherits it.
  2. Resolve every [inferred use] with the design team. The use drives the factor, and the factor drives the whole strategy.
  3. Hand the capacity sheet to the fire engineer as-is — they fill the right-hand columns and the checks complete. It saves a fee round.
  4. Treat [assumed route] rows as design questions, not drafting gaps: a route through another tenancy or a key-locked door is a strategy problem.
  5. Re-run after any plan revision. Routes and pinch points are functions of the layout, and both move silently.
  6. File the not-checked list with the takeoff. It defines what the fire engineer is still being asked to cover.

Remember: the arithmetic is the easy part. The takeoff's value is the space nobody scheduled and the route nobody drew — and neither shows up in a calculation that was never asked to look for them.

Triggering

When Claude reaches for it.

This is the description Claude itself reads to decide whether the skill applies. It is worth knowing, because it tells you exactly how to phrase the ask — and what the skill will decline.

occupancy-egress-takeoff

Turn floor plans, a room schedule or an area schedule into an occupancy and egress takeoff worksheet — every space listed with its use, area, the occupancy basis that would apply, the escape routes drawn, travel distances to be measured, exit widths as drawn, and stair and door capacities to be checked — each line naming the code clause to check it against and marked [to verify]. It is a measuring and query sheet for a fire engineer or building control submission; it never declares a capacity, a travel distance limit or compliance. Use this WHENEVER someone asks to "work out the occupancy", "do an egress takeoff", "how many people in this building", "check the escape routes", "what do we need for the fire strategy", "exit width check", "travel distances on this plan", or supplies plans ahead of a fire engineer's appointment. Do NOT use it to supply occupant load factors, travel distance limits or width-per-person figures from memory, to produce a fire strategy or declare compliance, or to replace a fire engineer — it prepares their brief.
