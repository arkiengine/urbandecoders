Quick reference

How to run it.

Turns dwelling drawings (or a written takeoff of them) into a Part M check worksheet: every access item, what the sheets actually evidence, the AD M reference to hold it against [to verify], and exactly what to measure and how. Not a verdict — the preparation for one. You clear the list with the drawings in CAD and your own copy of AD M open; that sitting-down is the compliance check.

Run it

Attach plans / a takeoff (and, ideally, your AD M Vol 1 pack) and ask:

Build a Part M check worksheet for Plot 6. M4(2) applies (condition 14). England.
Run an access review on these drawings — category not yet confirmed.
Export the check list as CSV for the technologist to run the CAD dims.

It will ask two scope questions once (M4 category + where it's set; jurisdiction/volume), then proceed — unanswered scope becomes the worksheet's first High-priority item, marked [architect to confirm].

The workbook

TabWhat it holds
Read meDrawing set + revs, scope status, evidence legend, formula counts, the "not a compliance assessment" statement. Always first.
Check worksheetOne row per checkable item: what's shown (verbatim), evidence tag, AD M ref [to verify], category sensitivity, measurement instruction, priority, action — plus two yellow input columns for your finding and the clause/edition you checked.
Queries & ambiguitiesSpecific, answerable questions (dimension conflicts, "indicative" layouts, TBC thresholds). Logged, never resolved.
Clause indexEvery reference used, one-line reminder in the skill's own words, all [to verify]. Missing cites listed as "architect to supply".
Not checkedHonest boundary: items on other sheets, other Approved Documents (K/G/B named [to verify]), input limitations.

Evidence tags — read the colour before trusting a row:

TagMeaning
Dimensioned (black)A written figure exists on the sheet. A claim to verify in CAD/site — not a measurement.
Annotated (black)A note without a figure ("level threshold"). Chase the substantiating detail.
Drawn (amber fill)Visible, no dimension. Not measurable from a flat PDF — routed to CAD or site.
Not shown (red)Expected item absent. Absence is a finding, never a pass; auto-generates a query.

Priority ranks cost-of-late-discovery (plan-level rework = High), never compliance. IDs CHK-<topic>-<nn> are permanent across worksheet revisions.

What it will not do — by design

  • Declare a verdict. "Complies"/"fails" never appears — even a 750mm door is written as compare stated value against the clause minimum [to verify], priority High. The build script aborts on verdict language.
  • Quote AD M figures from memory. References only, every one [to verify]; exact clauses only when taken from the pack you attached.
  • Measure a raster. No scaling PDFs or screenshots, ever.
  • Guess the M4 category. M4(2)/M4(3) apply only where imposed — it asks where the condition sets it, and blocks the sensitive rows until you answer.
  • Design the fix. No "widen D-01" — the query names the tension; you resolve it.
  • Pick between conflicting dimensions or read "726 door" as clear width. Both recorded verbatim, convention queried.
  • Reproduce AD M text. Clause names and own-words reminders only.
  • Web-search the site/client; no client names in filenames.

Work the output

  1. Read me — the Not shown and Drawn counts tell you in 10 seconds how much the drawings actually demonstrate.
  2. Settle the scope row first: confirm M4 category against the planning condition wording, and the volume/jurisdiction notes.
  3. Filter Check worksheet to High + red; run those CAD measurements before anything else.
  4. Hand the Measure (CAD/model) rows to the technologist (ask for the CSV export); send Queries to the designer/client as-is.
  5. With AD M open, fill the two yellow columns — your finding and the clause/edition checked. The "Findings completed" counter on Read me tracks progress.
  6. Re-run on the revised drawing set; IDs persist, so the two worksheets diff.

Remember: a worksheet that is half amber and red is a true statement about the drawing set, and cheap to fix at design stage. The dangerous output would be a green tick this tool has no basis to give. Test drive: run it on the Saxton Fold sample takeoff and score against its defect key.

Triggering

When Claude reaches for it.

This is the description Claude itself reads to decide whether the skill applies. It is worth knowing, because it tells you exactly how to phrase the ask — and what the skill will decline.

part-m-drawing-check

Turn residential drawings (plans, a drawing takeoff, or a written description of a drawing set) into a Part M access check worksheet — an editable .xlsx listing every access-and-mobility item, where it appears on the sheets, what the drawing actually shows (tagged Dimensioned / Annotated / Drawn / Not shown), which Approved Document M clause to check it against marked [to verify], and exactly what to measure and how. It is a measuring list and query sheet, never a compliance verdict. Use this WHENEVER someone asks to "check this plan against Part M", "run an access review on these drawings", "is this M4(2)/M4(3) compliant", "accessibility check", "wheelchair access check", "Part M audit", "what do I need to measure for Building Control", or supplies dwelling drawings and asks about door widths, turning circles, thresholds, WCs or approach routes. Do NOT use for Part B, G or K questions except to flag which document governs, and do NOT use it to obtain a pass/fail answer — the architect makes the call.
